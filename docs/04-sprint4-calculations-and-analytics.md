# Спринт 4. Расчёт среднего балла и аналитика

## Реализация
- **Средний по дисциплине:** `GradeCalculator.average(values)` = `sum / count`; для пустого списка — `null` (UI показывает «—», деления на ноль нет).
- **Общий средний:** то же по всем записям. В интерфейсе подписано: «Среднее арифметическое по всем записям, все оценки имеют одинаковый вес».
- **Фильтры:** вид работы и период (месяц) — `GradeFilter.apply`; фильтр по дисциплине — выбор дисциплины (главный экран → экран дисциплины, список в «Динамике»).
- **Сортировка:** по дате (↓/↑) и по оценке (↓/↑), вторичный ключ — дата.
- **Динамика:** `GradeCalculator.monthlyDynamics` — по календарным месяцам: число оценок, средний за месяц, накопленный средний, изменение к прошлому месяцу. Экран: линейный график (Canvas) + таблица.

## Контрольный набор для ручной проверки
Тестовые данные (см. Спринт 2). Рассчитайте вручную и сравните с приложением:

| Что | Формула | Ожидаемо |
|---|---|---|
| Математика | (5+4+3+5)/4 | **4,25** |
| Физика | (3+3+4+3)/4 | **3,25** |
| Информатика | (5+5+4+5)/4 | **4,75** |
| История | (4+4)/2 | **4,00** |
| Литература | нет оценок | **«—»** |
| Общий | 57/14 | **4,07** (4,0714…) |

Динамика «Все дисциплины» (месяцы от самого раннего):

| Месяц | Оценок | За месяц | Накопленный | Изменение |
|---|---|---|---|---|
| −3 мес. | 3 | 4,33 | 4,33 | — |
| −2 мес. | 4 | 4,00 | 4,14 | −0,33 |
| −1 мес. | 4 | 3,75 | 4,00 | −0,25 |
| текущий | 3 | 4,33 | 4,07 | +0,58 |

Все эти значения проверены независимой реализацией алгоритма; в проекте на них же построены юнит-тесты (`GradeCalculatorTest`).

**Контрольная точка:** значения в приложении совпадают с таблицами выше.
