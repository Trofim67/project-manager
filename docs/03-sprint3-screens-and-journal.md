# Спринт 3. Экран дисциплин и журнал оценок

| Задача | Реализация |
|---|---|
| Главный экран со списком дисциплин | `HomeScreen`: сводка + карточки; FAB «+» добавляет дисциплину; значки ✎/🗑 на карточке |
| Переход к дисциплине | `GradeApp`: маршрут `discipline/{disciplineId}` |
| Список оценок | `DisciplineScreen`: цветной кружок с оценкой (5 зелёный … 2 красный), тип, дата, комментарий (до 3 строк) |
| Форма создания | `GradeFormScreen`: оценка, дата (системный DatePicker, будущее запрещено), тип (список), комментарий (≤200 симв.) |
| Редактирование и удаление | та же форма с текущими значениями; удаление через `ConfirmDialog` |
| Сообщения об ошибках и пустые списки | ошибки под полями; заглушки: нет дисциплин / нет оценок / ничего не найдено по фильтру / нет данных для динамики |

## Валидация
| Поле | Правило | Сообщение |
|---|---|---|
| Оценка | целое 2–5 | «Введите целое число от 2 до 5» / «Оценка должна быть от 2 до 5» |
| Дата | ≤ сегодня | «Дата не может быть в будущем» |
| Комментарий | ≤ 200 | «Комментарий не длиннее 200 символов» |
| Название дисциплины | не пусто, ≤ 60, уникально | «Введите название дисциплины», … «Дисциплина с таким названием уже есть» |

Кнопка «Сохранить» не записывает данные, пока есть ошибки. Состояние форм переживает поворот экрана (`rememberSaveable`).

## Контрольная точка — демонстрация сценария
Открыть «Математику» → «+» → оценка 4, тип «Контрольная» → Сохранить → ✎ изменить на 5 → 🗑 удалить тестовую запись (с подтверждением).
