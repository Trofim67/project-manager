# Спринт 5. Целевой средний балл, UX и комплексное тестирование

## Калькулятор целевого балла
Формула: `нужная = цель × (n + 1) − сумма`.
Оценки целые, поэтому итог — **минимальная целая оценка**, при которой цель достигнута: `ceil(нужная − 1e-9)` (малая поправка защищает от ошибок double).

| Результат | Условие | Сообщение |
|---|---|---|
| Нужна оценка N | 2 < ceil ≤ 5 | «Нужна оценка: N» + расчёт |
| Цель уже достигается | ceil ≤ 2 | «При любой допустимой оценке (даже 2) средний будет не ниже цели» |
| Недостижима | ceil > 5 | «Даже за 5 средний балл станет X» |
| Недопустимая цель | цель вне 2–5 или не число | «Желаемый средний балл должен быть от 2 до 5» / «Введите число, например 4,5» |

### Проверка формулы (Математика: 5, 4, 3, 5; n = 4, сумма = 17)
| Цель | Расчёт | Нужная (точно) | Итог |
|---|---|---|---|
| 3,0 | 3·5 − 17 = −2 | −2,0 | уже достигается |
| 4,0 | 4·5 − 17 = 3 | 3,0 | **оценка 3** |
| 4,3 | 4,3·5 − 17 = 4,5 | 4,5 | **оценка 5** (с 4 было бы 4,20 < 4,3) |
| 4,4 | 4,4·5 − 17 = 5 | 5,0 | **оценка 5** (ровно 4,40) |
| 4,5 | 4,5·5 − 17 = 5,5 | 5,5 | **недостижимо**, максимум 4,40 |

Другие наборы: Физика (3,3,4,3) цель 4,0 → 7,0 → недостижимо (макс. 3,60); цель 3,5 → 4,5 → оценка 5. Общий балл (14 оц., сумма 57) цель 4,5 → 10,5 → недостижимо (макс. 4,13). Дисциплина без оценок, цель 4,0 → оценка 4.

## UX-улучшения
- Подсветка дисциплин со средним < 3,50: цвет **и** текстовое пояснение (не только цвет).
- Цветовое кодирование оценок в списке, различимые состояния ошибок и результатов.
- Длинные названия: обрезаются многоточием (заголовки — до 2 строк), ограничение 60 символов.
- Все диалоги удаления называют, что именно удаляется.

## Тестирование
- **Автоматические** (`app/src/test`): расчёт среднего, пустой список, порог «низкого», калькулятор (5 сценариев + граничные + пустой список + недопустимая цель + NaN), динамика, валидаторы, фильтры и сортировки — 22 теста.
- **Ручные**: 22 тест-кейса в `test-cases.md` (требование ≥ 10).
- Порядок: выполнить кейсы → записать результат → исправить ошибки → повторить проваленные.
