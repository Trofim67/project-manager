# Инструкция пользователя

**«Успеваемость»** — приложение для учёта оценок и среднего балла. Все данные хранятся только на вашем телефоне.

## Главный экран
Вверху — **общий средний балл** и количество оценок. Ниже кнопки **«Динамика»** и **«Целевой балл»** и список дисциплин с их средним баллом. Красная карточка — средний балл ниже 3,50, дисциплине нужно внимание.
Кнопка **«+»** — добавить дисциплину. Значки ✎ и 🗑 на карточке — изменить или удалить дисциплину (при удалении удаляются и все её оценки, приложение предупредит).
Меню **⋮**: «Загрузить тестовые данные» (для знакомства с приложением) и «Удалить все данные».

## Оценки
1. Нажмите на дисциплину — откроется список её оценок.
2. **«+»** — добавить оценку: введите значение (2–5), выберите дату и тип работы, при желании добавьте комментарий.
3. ✎ — изменить оценку, 🗑 — удалить (потребуется подтверждение).
4. **Фильтры:** «Вид» (контрольная, практическая…), «Период» (месяц). **Сортировка:** по дате или по оценке. «Сбросить» убирает фильтры. Сверху показывается и общий средний по дисциплине, и средний по выбранным фильтрам.

## Динамика
Показывает, как менялся средний балл по месяцам: график и таблица («за месяц», «накопленный», «изменение»). Сверху можно выбрать одну дисциплину.

## Целевой балл
1. Выберите дисциплину или «Общего балла».
2. Введите желаемый средний, например `4,5`.
3. Приложение скажет, какая оценка нужна за **следующую** работу. Если одной оценкой цель не достичь, оно сообщит, какой средний будет даже при пятёрке.

## Как считается средний балл
Сумма оценок ÷ количество оценок. Все оценки равноценны (веса не учитываются). Если оценок нет — показывается «—».

## Если что-то не так
Проверьте, что оценка — целое число от 2 до 5, а дата не в будущем. Сообщения об ошибках показываются под полем.
