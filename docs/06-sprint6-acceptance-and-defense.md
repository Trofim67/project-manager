## 4. Сценарий демонстрации (≈ 7 минут)
1. **Пустая база** → «Загрузить тестовые данные» (Product Owner, 1 мин): цель приложения, сценарии.
2. **Главный экран**: общий 4,07, подсветка Физики (Product Owner).
3. **Дисциплина «Математика»**: список оценок → добавить 4 «Лабораторная» → изменить на 5 → удалить; фильтр «Контрольная» + период; сортировка (Lead Developer, 2 мин).
4. **Динамика**: сверка с таблицей из Спринта 4 (QA).
5. **Целевой балл** для Математики: 4,0 → «3»; 4,4 → «5»; 4,5 → «недостижимо, максимум 4,40» (QA, 1 мин).
6. **Устойчивость**: ввод оценки 7 → ошибка; закрыть и открыть приложение → данные на месте (QA).
7. **Архитектура** (Lead Developer, 2 мин): слои `ui → ViewModel → Repository → Room`; `domain` — чистая логика без Android (поэтому тестируется юнит-тестами); `Flow` обновляет экраны при любом изменении базы.

## 5. Структура презентации (6–7 слайдов)
1. Название, команда, роли.
2. Проблема и цель приложения.
3. Экраны и сценарии (`wireframes.png`, `screen-flow.png`).
4. Модель данных (Discipline 1—N Grade, каскадное удаление) и архитектура.
5. Расчёты: формулы среднего и целевого балла, примеры 4,25 и «нужна 5».
6. Тестирование: 22 автотеста + 26 ручных кейсов, найденные и исправленные дефекты.
7. Итоги, что можно улучшить (веса работ, сценарный прогноз, порог риска).

## 6. Вопросы, к которым стоит подготовиться
| Вопрос | Краткий ответ |
|---|---|
| Почему оценки целые и 2–5? | Пятибалльная система; диапазон — константы в `GradeRules`, легко менять |
| Как считается средний? | сумма ÷ количество; пусто → `null`, показывается «—» |
| Почему калькулятор округляет вверх? | Оценки целые: нужна минимальная целая, при которой цель достигнута |
| Что с удалением дисциплины? | Каскадно, `ForeignKey.CASCADE`, после предупреждения с числом оценок |
| Зачем `epochDay`? | Просто хранить, сравнивать и группировать по месяцам, нет часовых поясов |
| Где данные после закрытия? | В SQLite (Room), файл `grades.db` во внутреннем хранилище приложения |
| Как добавить веса? | Словарь `workType → вес`, взвешенное среднее Σ(оценка·вес)/Σвес в `GradeCalculator` |
