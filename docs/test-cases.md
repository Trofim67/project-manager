# Тест-кейсы

Предусловие для большинства кейсов: приложение установлено, нажато «Загрузить тестовые данные» (если не указано иное).
Колонка «Результат» заполняется командой при выполнении (✔ пройден / ✘ не пройден + номер дефекта). «Авто» — есть ли юнит-тест на ту же логику.

| № | Область | Шаги | Ожидаемый результат | Авто | Результат |
|---|---|---|---|---|---|
| T-01 | Пустое состояние | Чистая установка → открыть приложение | «Дисциплин пока нет», кнопка загрузки тестовых данных; общий средний «—» | — | ☐ |
| T-02 | Тестовые данные | «Загрузить тестовые данные» | 5 дисциплин; общий средний 4,07; «Оценок: 14 • Дисциплин: 5»; Физика подсвечена | — | ☐ |
| T-03 | Повторная загрузка | Нажать «Загрузить тестовые данные» второй раз | Дублей нет, всё остаётся прежним | — | ☐ |
| T-04 | Создание дисциплины | «+» → «Химия», преподаватель пусто → Сохранить | «Химия» в списке, «Оценок пока нет», средний «—» | — | ☐ |
| T-05 | Валидация дисциплины | Название пустое / из пробелов / «математика» / 61 символ | Сохранение блокируется; сообщения: пусто, пусто, «уже есть», «не длиннее 60» | ✔ | ☐ |
| T-06 | Сохранение данных | Добавить оценку → смахнуть приложение из «недавних» → открыть | Оценка и средние на месте | — | ☐ |
| T-07 | Добавление оценки | Математика → «+» → 4, «Лабораторная», сегодня → Сохранить | Оценка в списке сверху; средний Математики = 21/5 = 4,20; общий 61/15 = 4,07 | ✔ | ☐ |
| T-08 | Граница оценки | Ввести 1, 6, 0, «abc», пусто, 4.5, 10 | Сохранение блокируется, сообщение «от 2 до 5» / «введите целое число» | ✔ | ☐ |
| T-09 | Допустимые границы | Ввести 2, затем 5 | Оба значения сохраняются | ✔ | ☐ |
| T-10 | Дата в будущем | Открыть выбор даты | Будущие даты недоступны в диалоге; (на уровне логики — ошибка «Дата не может быть в будущем») | ✔ | ☐ |
| T-11 | Редактирование | ✎ у оценки 3 → заменить на 5 → Сохранить | Оценка обновлена; средний пересчитан сразу | — | ☐ |
| T-12 | Удаление оценки | 🗑 → «Отмена»; затем 🗑 → «Удалить» | После «Отмены» запись цела; после «Удалить» исчезла, средний пересчитан | — | ☐ |
| T-13 | Удаление последней оценки | Удалить все оценки у «Истории» | Заглушка «Оценок по этой дисциплине пока нет»; средний «—», без падения | ✔ | ☐ |
| T-14 | Каскадное удаление | Удалить «Физику» | Диалог: «будут удалены все её оценки (4)»; после подтверждения дисциплина и оценки исчезли; общий средний пересчитан | — | ☐ |
| T-15 | Фильтр по типу | Математика → Вид: «Контрольная» | 2 оценки (5 и 3); «По выбранным фильтрам: 4,00 (оценок 2 из 4)» | ✔ | ☐ |
| T-16 | Фильтр по периоду | Математика → Период: любой месяц | Только оценки этого месяца; сочетается с фильтром по виду | ✔ | ☐ |
| T-17 | Пустой результат фильтра | Вид: «Экзамен» | «Ничего не найдено…»; «Сбросить» возвращает список | ✔ | ☐ |
| T-18 | Сортировка | Переключить 4 варианта сортировки | Порядок меняется (дата ↓↑, оценка ↓↑) | ✔ | ☐ |
| T-19 | Динамика | Главный → «Динамика» | Таблица и график совпадают с таблицей в `04-sprint4…md` (4,33 / 4,00 / 3,75 / 4,33) | ✔ | ☐ |
| T-20 | Динамика без данных | «Удалить все данные» → «Динамика» | Заглушка «Пока нечего показывать» | ✔ | ☐ |
| T-21 | Калькулятор: расчёт | «Целевой балл» → Математика → 4,4 / 4,0 / 4,3 | «Нужна оценка: 5» / «3» / «5» | ✔ | ☐ |
| T-22 | Калькулятор: граничные | Математика → 4,5; 3,0; 1,5; 5,5; «abc»; запятая и точка (4,4 и 4.4) | «Недостижима, максимум 4,40»; «Уже достигается»; ошибка диапазона ×2; ошибка формата; запятая и точка дают одинаковый результат | ✔ | ☐ |
| T-23 | Подсветка | Главный экран | Физика (3,25) красная + текст причины; остальные — обычные | ✔ | ☐ |
| T-24 | Длинное название | Создать дисциплину из 60 символов | Название обрезано многоточием, вёрстка не ломается, заголовок экрана обрезан | — | ☐ |
| T-25 | Поворот экрана | В форме оценки ввести данные → повернуть устройство | Введённые данные сохранились | — | ☐ |
| T-26 | Навигация | Пройти все экраны и вернуться кнопкой «Назад» | Каждый экран возвращает на предыдущий; приложение не закрывается раньше времени | — | ☐ |
